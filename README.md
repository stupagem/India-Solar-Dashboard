# India Solar Dashboard 🇮🇳☀️

An interactive Power BI dashboard tracking India's cumulative installed solar capacity (2018–2025), broken out by installation type — Ground-Mounted, Rooftop (Industrial/Commercial/Residential), Hybrid, and Off-Grid — with state-wise capacity rankings and year-on-year trend analysis.

![Dashboard Preview](https://github.com/stupagem/India-Solar-Dashboard/blob/main/Solar%20Dashboard%20SS.png)

---

## 📊 Overview

This project visualizes the growth of India's solar power capacity from 2018 to 2025, covering both ground-mounted and rooftop segments. It is designed to help identify:

- Which states are leading India's solar capacity build-out
- How capacity is split between ground-mounted vs. rooftop installations
- The composition of rooftop solar (Industrial, Commercial, Residential, Public Sector)
- Year-on-year growth trends by installation type

## 🧩 Dashboard Pages

| Page | Description |
|---|---|
| **India's Solar Profile** | Total installed solar capacity (ground-mounted + rooftop) with state-wise rankings |
| **Solar Capacity Installed (2018–2025)** | Breakdown by solar type (Ground Mounted, Hybrid, Off-Grid, Rooftop) with a state-wise bar chart and year-on-year trend line |
| **Rooftop Capacity Installed (2018–2025)** | Rooftop-only view segmented into Industrial, Commercial, Residential, and Public Sector, with state-wise rankings and a time-series trend |
| **India's Rooftop Solar Profile** | Dedicated rooftop drill-down with capacity rank tables for each rooftop segment |

## ⚙️ Key Features

- **KPI Cards** — quick-glance totals for overall, ground-mounted, and rooftop capacity
- **Ranked Bar Charts** — state-wise capacity leaders across each segment
- **Donut Charts** — capacity share by solar/installation type
- **Time-Series Trend Lines** — year-on-year capacity additions by type (2018–2025)
- **Interactive Filtering** — drill into any state, year, or installation type across all pages

## 🗂️ Data Sources

- [Ministry of New and Renewable Energy (MNRE)](https://mnre.gov.in/) — official state-wise and year-wise installed solar capacity statistics
- [Bridge to India](https://bridgetoindia.com/) — market intelligence and research reports on India's rooftop and ground-mounted solar segments

*Data was compiled and structured manually from publicly available reports and statistics published by the above sources.*
